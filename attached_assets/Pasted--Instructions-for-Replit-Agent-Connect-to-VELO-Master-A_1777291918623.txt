# Instructions for Replit Agent: Connect to VELO Master AI

You are building AI agents inside a Flask web application. These agents connect to a **master AI called VELO** running on a separate server. VELO is the brain — your agents are specialized workers that can request VELO's capabilities and receive commands from VELO.

**Everything is dynamic.** No hardcoded command lists. Agents self-register their capabilities. VELO discovers what's available at runtime. When you add new features to this Flask app, the agent registers them and VELO automatically knows.

## Architecture

```
VELO Master (FastAPI)
  ├── /api/capabilities       ← discover what VELO can do (dynamic)
  ├── /api/agent-gateway      ← your agents call this to use VELO's tools
  ├── /api/agent-register     ← your agents register here on startup
  ├── /api/agent-command      ← VELO calls YOUR endpoints to command your agents
  └── /api/agents             ← list all connected agents + their capabilities

Your Flask App
  ├── /api/velo/command       ← VELO sends commands here (single dynamic endpoint)
  └── /api/velo/status        ← VELO checks health + state
```

## Part 1: Build the VELO Integration Layer

### 1A. VELO Client — call VELO's tools (your app → VELO)

```python
# velo_client.py

import requests
import os

VELO_URL = os.environ.get("VELO_MASTER_URL", "http://localhost:8000")
VELO_AGENT_KEY = os.environ.get("VELO_AGENT_KEY", "")


class VeloClient:
    """Dynamic client for Flask agents to call VELO master capabilities."""

    def __init__(self):
        self.base_url = VELO_URL
        self.headers = {
            "Authorization": f"Bearer {VELO_AGENT_KEY}",
            "Content-Type": "application/json",
        }
        self._capabilities = None

    def discover(self) -> list[dict]:
        """Fetch VELO's current capabilities. Call on startup or when needed."""
        resp = requests.get(f"{self.base_url}/api/capabilities", headers=self.headers, timeout=10)
        resp.raise_for_status()
        self._capabilities = resp.json().get("capabilities", [])
        return self._capabilities

    def use_tool(self, agent_id: str, tool_name: str, tool_input: dict) -> dict:
        """
        Use any VELO tool dynamically.
        tool_name: from discover() — e.g. "langchain_agent", "deploy", "browser_control"
        tool_input: matches the tool's input_schema from discover()
        """
        resp = requests.post(
            f"{self.base_url}/api/agent-gateway",
            headers=self.headers,
            json={"agent_id": agent_id, "tool_name": tool_name, "tool_input": tool_input},
            timeout=120,
        )
        resp.raise_for_status()
        return resp.json()

    def report_event(self, agent_id: str, event_type: str, data: dict) -> dict:
        """Report an event to VELO. VELO may auto-handle (e.g. escalations get auto-researched)."""
        resp = requests.post(
            f"{self.base_url}/api/agent-gateway",
            headers=self.headers,
            json={
                "agent_id": agent_id,
                "tool_name": "report_event",
                "tool_input": {"event_type": event_type, "data": data},
            },
            timeout=30,
        )
        resp.raise_for_status()
        return resp.json()


velo = VeloClient()
```

### 1B. Command Receiver — accept commands from VELO (VELO → your app)

**One dynamic endpoint.** Commands are routed by name to handler functions. Adding a new capability = adding a handler function + registering it.

```python
# velo_endpoints.py

from flask import Blueprint, request, jsonify
import os

velo_bp = Blueprint("velo", __name__, url_prefix="/api/velo")
VELO_AGENT_KEY = os.environ.get("VELO_AGENT_KEY", "")

# ---------------------------------------------------------------------------
# Dynamic command registry — add handlers here, they auto-register with VELO
# ---------------------------------------------------------------------------
_command_handlers = {}


def velo_command(name: str, description: str = "", params_schema: dict = None):
    """Decorator to register a command handler."""
    def decorator(func):
        _command_handlers[name] = {
            "handler": func,
            "description": description,
            "params_schema": params_schema or {},
        }
        return func
    return decorator


def get_registered_capabilities() -> list[dict]:
    """Return all registered capabilities for VELO registration."""
    return [
        {"name": name, "description": info["description"], "params_schema": info["params_schema"]}
        for name, info in _command_handlers.items()
    ]


# ---------------------------------------------------------------------------
# Auth
# ---------------------------------------------------------------------------
def verify_velo_key():
    auth = request.headers.get("Authorization", "")
    if VELO_AGENT_KEY and (not auth.startswith("Bearer ") or auth[7:] != VELO_AGENT_KEY):
        return False
    return True


# ---------------------------------------------------------------------------
# Single dynamic command endpoint
# ---------------------------------------------------------------------------
@velo_bp.route("/command", methods=["POST"])
def handle_command():
    """VELO sends any command here. Routed by command name to registered handlers."""
    if not verify_velo_key():
        return jsonify({"error": "unauthorized"}), 401

    data = request.json
    command = data.get("command", "")
    params = data.get("params", {})

    handler_info = _command_handlers.get(command)
    if not handler_info:
        return jsonify({
            "error": f"Unknown command: {command}",
            "available_commands": list(_command_handlers.keys()),
        }), 400

    try:
        result = handler_info["handler"](params)
        return jsonify({"status": "ok", "result": result})
    except Exception as e:
        return jsonify({"status": "error", "error": str(e)}), 500


@velo_bp.route("/status", methods=["GET"])
def app_status():
    if not verify_velo_key():
        return jsonify({"error": "unauthorized"}), 401
    return jsonify({
        "status": "ok",
        "available_commands": list(_command_handlers.keys()),
        # Add dynamic stats: user_count, active_sessions, error_count, uptime, etc.
    })
```

### 1D. Auto-Register with VELO on Startup

```python
# In your Flask app startup (app.py)

from velo_endpoints import velo_bp, get_registered_capabilities
import velo_handlers  # importing this registers all @velo_command handlers

app.register_blueprint(velo_bp)

# Register with VELO after app starts
import requests, os

def register_with_velo():
    """Register this app's agents with VELO so it knows what we can do."""
    velo_url = os.environ.get("VELO_MASTER_URL", "http://localhost:8000")
    agent_key = os.environ.get("VELO_AGENT_KEY", "")
    site_url = os.environ.get("SITE_URL", "http://localhost:5000")

    capabilities = get_registered_capabilities()

    for agent_type in ["admin_ai", "visitor_ai"]:
        try:
            requests.post(
                f"{velo_url}/api/agent-register",
                headers={"Authorization": f"Bearer {agent_key}"},
                json={
                    "agent_id": agent_type,
                    "agent_type": agent_type,
                    "base_url": site_url,
                    "endpoint": f"{site_url}/api/velo/command",  # single dynamic endpoint
                    "capabilities": capabilities,
                    "metadata": {"framework": "flask", "version": "1.0"},
                },
                timeout=10,
            )
            print(f"[VELO] Registered {agent_type} with {len(capabilities)} capabilities")
        except Exception as e:
            print(f"[VELO] Failed to register {agent_type}: {e}")

# Call after app is ready
with app.app_context():
    register_with_velo()
```

## Part 2: How to Add New Capabilities

**To add something new your agents can do** — just write a handler:

```python
@velo_command("new_capability", description="What it does", params_schema={...})
def new_capability(params):
    # ... your logic ...
    return {"result": "..."}
```

That's it. On next startup, it auto-registers with VELO. VELO's AI will see it in the capabilities list and can call it.

**To use a new VELO tool** — VELO adds tools independently. Your agents discover them:

```python
# Refresh capabilities
capabilities = velo.discover()
# Now use whatever's available
result = velo.use_tool("admin_ai", "some_new_tool", {"param": "value"})
```

## Part 3: How Communication Flows

### Visitor asks something the AI can't answer:
1. Visitors AI tries local knowledge base
2. Can't answer → `velo.report_event("visitor_ai", "escalation", {"question": "...", "session_id": "..."})`
3. VELO auto-researches and returns answer
4. OR VELO calls back with `command: "escalate_response"` to push answer to visitor

### VELO wants analytics:
1. User asks VELO "how many signups this week?"
2. VELO sees admin_ai has `get_analytics` capability
3. Calls it with `{"period": "week"}`
4. Your handler queries DB, returns numbers

### VELO controls client features (super admin):
1. Owner tells master VELO "Upgrade Acme Corp to Pro plan"
2. VELO calls `client_velo` tool → `command_agent` → Acme's admin_ai → `manage_features`
3. Handler receives `{"action": "apply_plan", "plan": "pro"}`
4. All Pro features get enabled, non-Pro features disabled
5. VELO confirms to owner

### VELO toggles a single feature:
1. Owner says "Disable email campaigns for Acme"
2. VELO → Acme's admin_ai → `manage_features` with `{"action": "set", "feature": "email_campaigns", "enabled": false}`
3. Feature disabled immediately

### Adding a capability later:
1. You write `@velo_command("generate_invoice", ...)` in your Flask app
2. Restart Flask → auto-registers with VELO
3. VELO's AI now knows it can generate invoices and will use it when relevant


## Part 4: Multi-Tenant Setup

When this Flask app + VELO pair is cloned for a business client:

```
Owner's Master VELO (super admin)
    ├── Client A's VELO ←→ Client A's Flask Site
    ├── Client B's VELO ←→ Client B's Flask Site
    └── Client C's VELO ←→ Client C's Flask Site
```

### Each client VELO registers with master on startup:

```python
# In client VELO's startup (main.py lifespan)
import httpx, os

async def register_with_master():
    master_url = os.environ.get("VELO_MASTER_URL", "")
    super_key = os.environ.get("VELO_SUPER_KEY", "")
    client_id = os.environ.get("VELO_CLIENT_ID", "")
    if not master_url or not client_id:
        return
    try:
        async with httpx.AsyncClient(timeout=10) as client:
            await client.post(
                f"{master_url}/api/clients/register",
                headers={"Authorization": f"Bearer {super_key}"},
                json={
                    "client_id": client_id,
                    "client_name": os.environ.get("VELO_CLIENT_NAME", client_id),
                    "velo_url": os.environ.get("VELO_PUBLIC_URL", "http://localhost:8000"),
                    "site_url": os.environ.get("SITE_URL", ""),
                    "agent_key": os.environ.get("VELO_AGENT_KEY", ""),
                    "metadata": {},  # plan, region, owner, whatever you want
                },
            )
    except Exception as e:
        print(f"[VELO] Failed to register with master: {e}")
```

### Master inspects any client dynamically:

The master VELO can call `GET /api/clients/{id}` which auto-discovers that client's tools, agents, and agent capabilities at runtime. No config needed — if the client's Flask app registered new commands, the master sees them immediately.
