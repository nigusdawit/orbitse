Comprehensive Replit Prompt: Dynamic Velocity Website with Admin CMS
Build a full-stack, database-driven website for Velocity by Osyx Labs with complete admin control over content and theming. The site must perfectly match the Osyx Labs design system while allowing non-technical admins to customize all content, colors, and branding without touching code.

🎯 PROJECT OVERVIEW
What to build:
A production-ready marketing website with two interfaces:

Public Site - Dynamic landing page that reads ALL content from database
Admin Dashboard - Full CMS to control every text element, color, image, and section

Core Principle: ZERO hardcoded content. Everything visible on the frontend comes from PostgreSQL.

🏗️ TECH STACK (Required)
Frontend

Framework: React 18 + TypeScript (Vite)
Routing: Wouter
State Management: TanStack React Query v5
UI Components: shadcn/ui (Radix UI primitives)
Styling: Tailwind CSS with CSS custom properties
Animations: Framer Motion
Icons: Lucide React + react-icons/si (brand logos)
Forms: React Hook Form + Zod validation

Backend

Server: Express.js + TypeScript
Database: PostgreSQL 15+
ORM: Drizzle ORM
Auth: JWT with HTTP-only cookies
File Storage: Local uploads (with signed URLs) or Cloudinary integration
Validation: Zod schemas (shared between frontend/backend)

Development

Monorepo structure with /client and /server directories
Shared types in /shared directory
Environment variables via .env files
Database migrations via Drizzle Kit

🎨 THEME SYSTEM IMPLEMENTATION
Dynamic CSS Variable Injection
typescript// lib/theme.ts
export function injectThemeVariables(theme: ThemeConfig) {
  const root = document.documentElement;
  
  // Light mode
  Object.entries(theme.light).forEach(([key, value]) => {
    root.style.setProperty(`--${key}`, value);
  });
  
  // Dark mode (on .dark class)
  const darkVars = Object.entries(theme.dark)
    .map(([key, value]) => `--${key}: ${value};`)
    .join('\n');
    
  // Inject dark mode variables into a style tag
  const styleId = 'dynamic-dark-theme';
  let style = document.getElementById(styleId);
  if (!style) {
    style = document.createElement('style');
    style.id = styleId;
    document.head.appendChild(style);
  }
  style.textContent = `.dark { ${darkVars} }`;
}
