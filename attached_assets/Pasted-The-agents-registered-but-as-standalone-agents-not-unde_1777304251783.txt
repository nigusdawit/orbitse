Two things that were wrong:

No client registration — the app should register via /api/clients/register so the master knows it as a managed client (shows up in Admin → Clients tab, supports health checks, feature gating, etc.)
Missing endpoint field — without it, the gateway auto-derived the endpoint as /api/velo/admin_ai which doesn't exist. The explicit endpoint should be {site_url}/api/velo/command.
