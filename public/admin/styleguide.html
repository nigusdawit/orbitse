The admin design system

Every component below is defined in public/admin/theme.css and is theme-aware through the --admin-* CSS variables. Build new admin panels by composing these gx-* classes — don't write bespoke CSS unless a component genuinely doesn't exist yet. Tweak the controls in the top bar to see how the Appearance tokens reshape the whole kit at once. Full maintainer guide: templates/admin/README.md.

This is a static reference page (no build step, no auth, no data). It links the same stylesheets as the real dashboard, so what you see is what ships.

Buttons

gx-btn is the base; add gx-btn-primary (accent gradient) or gx-btn-ghost (transparent). gx-icon-btn is the square icon-only variant.

<button class="gx-btn">Default</button>
<button class="gx-btn gx-btn-ghost">Ghost</button>
<button class="gx-icon-btn" aria-label="Edit"><svg…></svg></button>

Cards

gx-card is the glass container. gx-card-h is its header row, usually with a gx-ico (accent-tinted icon chip).

Card body text. Compose stats, forms, tables, or lists inside.

Forms & fieldsets

Group fields with gx-fieldset; lay them out two-up with gx-grid-fields (add col-2 to span). Each field is gx-field → gx-label + gx-input. Mark required with gx-req; add a hint bubble with gx-help.

Tier details
<div class="gx-fieldset">
  <div class="gx-fieldset-h">Tier details</div>
  <div class="gx-grid-fields">
    <div class="gx-field">
      <label class="gx-label">Name <span class="gx-req">*</span></label>
      <input class="gx-input" placeholder="e.g. Summer Peak">
    </div>
    <div class="gx-field col-2">
      <label class="gx-label">Description</label>
      <textarea class="gx-input"></textarea>
    </div>
  </div>
</div>
