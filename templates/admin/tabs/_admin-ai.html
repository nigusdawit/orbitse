Admin AI

Configure your admin assistant — the personas it can adopt and the slash-commands, capability cards & starter chips it surfaces in the chat. Changes go live on the next reply; no restart needed. Built-ins can be edited or reset to default; add your own for custom workflows.

{# ---- Personas ---- #}

A persona shapes how the assistant answers (a system-prompt addition) and which tools it focuses on (a tool filter). “Auto” lets the router pick one per turn. After adding a persona, describe it in the Persona Router prompt (AI Prompts tab) so Auto can route to it.

Slash-commands appear in the chat's “/” palette. Each seeds a prompt into the composer (and can pin a persona). Use Leave caret to type arg when the command ends mid-sentence for the operator to finish.
