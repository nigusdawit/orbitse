Custom Skills

Extend the visitor chat agent with your own knowledge, webhook calls, and parameterised database queries. Anything you save here becomes a tool the AI can call mid-conversation.

Knowledge entries

Short topical notes the agent searches via the lookup_knowledge skill. Keep one fact per entry.

Webhook skills

HTTP calls the agent can trigger. Localhost and private-network URLs are blocked; only public HTTPS endpoints work.

SQL skills

Parameterised SELECT queries the agent can run. Use %(name)s placeholders for arguments. Only one SELECT statement per skill; 5-second budget; up to 100 rows returned.
