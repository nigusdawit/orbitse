How to apply this on a fresh install

  1. Download the JSON above.
  2. Open the new install's /setup wizard, or POST the JSON to its /api/velo/command endpoint with command bootstrap_install (template = the JSON contents).
  3. Edit admin_user.email + any business-specific text (site name, contact info, FAQs) before applying — every clone needs its own owner email.
  4. Re-runs are idempotent for settings, features, FAQs (deduped on canonical question), and admin records (UPSERT by natural key). Content rows are INSERT-only and will duplicate on re-run.
