    🌐 WordPress Plugin

    Embed your AI Concierge in any WordPress site with single sign-on.

    🔌 Installation Steps
    1. After provisioning, go to Admin → WordPress Plugin tab to download the .zip file.
    2. In WordPress, go to Plugins → Add New → Upload Plugin and upload the .zip.
    3. Activate the plugin and visit Settings → AI Concierge.
    4. Enter your Platform URL (this Repl's URL) and the Embed Key generated during provisioning.
    5. Place a shortcode on any page or widget area.
    📋 Shortcodes
    [ai_concierge]                       — Full embedded platform
[ai_concierge chat_only="true"]      — Chat widget only
[ai_concierge gallery="true"]        — Gallery view only
[ai_concierge section="pricing"]     — Jump to a specific section
    🔐 Single Sign-On (SSO)
    Logged-in WordPress users are automatically signed in to the concierge with their WordPress identity.
    // In your theme's functions.php:
add_filter('ai_concierge_sso_user', function($user) {
    $wp = wp_get_current_user();
    $user['email'] = $wp->user_email;
    $user['name']  = $wp->display_name;
    return $user;
});
    The Embed Key is generated when you click Provision. It will appear in Admin → WordPress Plugin after setup completes.
